PROPOSED SOLUTION

Proposed Solution & Prototype

  • End-to-end VAPT audit framework & automated security test suite for World Monitor.
  • Evaluates 7 vulnerability vectors across Edge proxies, CORS rules, and DOM parsers.

Addressing NTRO Requirements

  • Provides CVSS v3.1 metrics, root cause analysis, and 5 production-ready code patches.
  • Includes executable Python test suite (run_security_audit.py) for CI/CD regression testing.
Slide 3
TECHNICAL APPROACH

Technologies & Frameworks

  • Python 3, TypeScript/JavaScript, Vercel Edge Runtime.
  • OWASP WSTG v4.2, OWASP Top 10 API (2023), NIST SP 800-115, CVSS v3.1.

Audit Methodology

  • 1. Static Application Security Testing (SAST) on Edge handlers.
  • 2. Edge reverse engineering of TOCTOU DNS rebinding gaps.
  • 3. Dynamic verification via Python PoC test harness (100% pass rate).
  • 4. Developing socket pinning & recursive redirect validation patches.
Slide 4
FEASIBILITY AND VIABILITY

Feasibility & Risks Identified

  • Test suite executes in under 5 seconds with zero external library dependencies.
  • VULN-01/03 (High): DNS Rebinding SSRF to AWS/GCP IMDS (169.254.169.254).
  • VULN-02 (High): RSS Proxy domain allowlist bypass via open HTTP redirects.

Hardening Controls

  • Socket Pinning: Single-pass IP connection with Host retention (patch_mcp_proxy_ssrf.ts).
  • Redirect Inspection: Recursive DNS IP validation on redirect hops (patch_rss_proxy_redirects.js).
  • CORS Sanitization: Neutralizing credentials reflection on refusal headers (patch_cors_refusal.js).

IMPACT AND BENEFITS

Infrastructure Protection

  • Blocks unauthorized access to 169.254.169.254, protecting AWS/GCP instance tokens.
  • Prevents malicious pivoting to loopback addresses (127.0.0.1:8080) and Redis ports.
  • Protects Edge functions against CPU resource exhaustion attacks.

Operational Value for NTRO

  • Ensures OSINT geospatial dashboard views remain immune to stored DOM XSS payloads.
  • Binds anonymous session tokens to IP subnets and reduces TTL to 1 hour.
  • Immediate drop-in production code patches and automated CI/CD regression runner.
