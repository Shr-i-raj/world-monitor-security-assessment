Key Finding
DNS Rebinding TOCTOU in Edge Runtime

VULN-01 Deep Dive: api/mcp-proxy.ts

  • Edge Runtime Constraint: Vercel Edge Runtime native fetch() cannot pin HTTP sockets to pre-resolved IP addresses.
  • Check Phase: Pre-flight DoH resolution checks target.attacker.com. Returns 93.184.216.34 (public IP) and passes filter.
  • Use Phase: Handler invokes native fetch(). Vercel Edge Runtime executes a second independent DNS resolution.
  • Exploit Vector: Attacker sets DNS TTL = 0. Second query returns 169.254.169.254 (AWS EC2 Metadata Endpoint), exfiltrating internal cloud credentials.
  • Our Fix: Developed patch_mcp_proxy_ssrf.ts introducing socket-pinned single-pass IP connection handling with Host header retention.
